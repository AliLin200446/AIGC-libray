# Original mock media

Twelve original FRAMEFIELD geometric animations, recorded locally from an HTML canvas as WebM, with JPEG samples at the timestamps declared in `server/clips/mock.ts`. These files contain no stock footage or third-party imagery. They are dedicated to CC0-1.0 for use as workflow fixtures.

The mock analyses are authored fixtures, not model results or verified camera classifications. These assets are private development inputs, excluded from production output. They are copied into the private mock queue by `npm run clips:mock`.
